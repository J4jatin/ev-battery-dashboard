# Frontend — EV Battery Intelligence Dashboard

React 19 + TypeScript + Vite. See the [project README](../README.md) for
architecture, setup and deployment, and [STUDY_GUIDE.md](../STUDY_GUIDE.md) for
the design decisions.

```bash
cp .env.example .env
npm install
npm run dev        # dev server on :5173
npm run test       # vitest
npm run lint       # eslint
npm run typecheck  # tsc -b
npm run build      # production build
```
